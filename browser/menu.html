Mobile Fullscreen Setup

Install as a Web App to play borderless in true fullscreen without browser address bars:

iPhone (Safari)
  1. Tap Share ⎋ (square with arrow)
  2. Select Add to Home Screen ＋
  3. Launch from your Home Screen
Android (Chrome)
  1. Tap Menu ⋮ (three dots at top right)
  2. Select Install app or Add to Home screen
  3. Launch from your Home Screen

Controls

Use the settings below to change your driving keys. The game must use its default keyboard bindings.

F9
Open the game menu
Enter
Launch the game
